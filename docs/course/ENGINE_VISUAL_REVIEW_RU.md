# Предложения по инфографике раздела «Движок JavaScript»

Дата: 4 ноября 2026 года. Статус: предложение для обсуждения, без изменения утверждённых уроков.

Рассмотрены все 19 русских уроков, их Markdown и компоненты схем. Основа оформления — текущий курс Advanced JavaScript. После просмотра SDK Алекс отменил требование использовать SVG: переноса графики на SVG этот документ не предлагает. Сохраняем HTML/CSS, понятные цветовые акценты и полезные интерактивные схемы. Canvas нужен только там, где частая перерисовка действительно оправданна.

Главная возможность улучшения — точнее показывать связи и последствия действий. Не нужно перерисовывать удачные элементы только ради новой технологии.

## Приоритет

1. **AST и графы ссылок:** 04, 12, 13, 15. Видимые связи дают наибольший учебный эффект.
2. **Передача результата и порядок исполнения:** 02, 05, 10, 18. Действие должно показывать результат, а не только новую подсветку.
3. **Точечные правки:** 01, 06, 09, 11, 16, 17.
4. **Сохранить удачное:** 03, 07, 08, 14, 19; изменения только при конкретной проблеме.

## Условия будущей переработки

- Сначала согласовать конкретные уроки и изменения. Этот документ не меняет содержание курса.
- Начать с русского варианта; перевод — отдельное поручение после проверки.
- Не менять адреса, прогресс, ключи перевода и смысл примеров.
- Для ввода использовать ограниченные проверяемые данные; не выполнять произвольные фрагменты кода.
- Проверить обе темы, ширины 375 и 1280 пикселей, клавиатуру, сброс и повторное выполнение.
- Анимация показывает причинную связь; при reduced motion состояние меняется без движения.
- Не объединять все схемы в один универсальный ряд одинаковых карточек.
