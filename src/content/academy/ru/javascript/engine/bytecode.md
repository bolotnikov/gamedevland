Байткод — компактные инструкции для виртуальной машины. Вместо исходной записи «сложить значения» появляется последовательность операций: получить аргумент, загрузить значение, выполнить сложение, вернуть результат.

```js
function add(a, b) {
  return a + b;
}
```

Ниже показан **псевдобайткод**, а не вывод конкретной версии V8. В реальном [Ignition](https://v8.dev/docs/ignition) есть аккумулятор, регистры виртуальной машины, специальные инструкции и служебные данные. Их формат меняется.

Нужно различать три вещи: **текст программы**, **байткод для интерпретатора** и **машинный код для CPU**. Компактная промежуточная форма помогает начать выполнение без немедленного запуска дорогого оптимизирующего компилятора.

В симуляции аргументы равны `2` и `3`. Пройдём инструкции последовательно и определим, на каком шаге появляется результат. Обобщённая операция сложения ещё должна учитывать семантику типов JavaScript.
