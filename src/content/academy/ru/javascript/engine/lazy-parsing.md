Рассмотрим SDK с логикой редактора уровней, которая не вызывается во время рекламной сессии. Полностью разбирать и компилировать каждую такую функцию на старте было бы дорого.

V8 использует **[lazy parsing](https://v8.dev/blog/preparser)**: для подходящих функций preparser делает сокращённый проход, а полная подготовка откладывается. Это не означает, что движок «игнорирует всё внутри»: нужно проверить синтаксические условия и собрать необходимые сведения об области видимости.

```js
function startGame() { /* Needed immediately */ }
function openEditor() { /* May never be called */ }
startGame();
```

Кэширование, эвристики и конкретная версия движка влияют на фактический путь. По одной строке кода нельзя определить точный момент компиляции. При подготовке playable сначала исключим ненужный код из поставки: ленивый разбор не отменяет передачу, декодирование и хранение исходника.
