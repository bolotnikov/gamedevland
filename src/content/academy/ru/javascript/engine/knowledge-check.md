Теперь — короткая проверка после теории. Вопросы отделяют правила языка от возможных деталей реализации. Здесь нет задания угадать, после какого числа вызовов [V8](https://v8.dev/blog/maglev) переключит уровень: приложение не имеет такого универсального контракта.

После выбора ответов нажмём «Проверить ответы». Для каждого вопроса появится пояснение и ссылка на соответствующий шаг. Ответы сохраняются в этом браузере, поэтому к проверке можно вернуться.

**Результат этой самопроверки не равен итоговой оценке за урок.** Для оценки нужно объяснить механизм своими словами и применить его к задаче игрового SDK. Это будет на следующем шаге: вопросы для разбора с преподавателем.
